# 🎤 LUNES 12 OCT (tarde) — DRILL DE HÁBITOS + PARTE 3 · SET Nº2 (tecnología)

## A. Drill de los 5 errores: **4/6**
| Objetivo | |
|---|---|
| ***for*** a few years | ✅ *for almost five years* |
| ***I usually…*** | ✅ |
| ***related to*** | ❌ no apareció |
| ***hang out at*** | ✅ |
| ***I'd say*** | ❌ ***I will say*** (2 veces, con la instrucción escrita en frente) |
| ***used to*** en pasado | ✅✅ *I used to ride horses* |

🔴 ***I will say*** **es el hábito más fuerte** (viene de traducir "diría" → *I'd say*).
Otros: *different **to*** → **from** · *places **to do*** → **to go** · ***in the night*** → **at night** (repetido) · *for young people, **is**…* → **it's** · doble sujeto *we the both of us… we* · *go **to** long rides* → **on** · *sundown* → **sunset**.
